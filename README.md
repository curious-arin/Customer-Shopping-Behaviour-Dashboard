# 🛍️ Customer-Shopping-Behaviour-Dashboard

-----

## 🙂 Overview

This project focuses on analyzing customer shopping behaviour to uncover purchasing patterns, product preferences, spending trends, and customer loyalty. using python for exploratory data analysis, postgreSQL for data analysis, and powerbi for visualization, i explored consumer shopping data to identify meaningful business insights.

*The goal was to understand customer behaviour, identify factors influencing purchasing decisions, optimize marketing strategies, improve customer engagement, and support data-driven business decisions.*

-----

## 📊 Data Analysis Workflow

**Python for eda → PostgreSQL for answering business questions → Powerbi for dashboarding**

* Python
* PostgreSQL
* Power BI
